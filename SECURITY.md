# Security

This app can send text and Enter to terminals under your SSH account. Use it
only with accounts and hosts you intend to control, and verify SSH host keys
before accepting them.

For credential exposure, host-verification bypasses, or unintended command
execution, use the repository's private vulnerability reporting feature if
available. Do not post passwords, private keys, real terminal captures, or
unredacted machine details in public issues. Ordinary bugs can be reported with
a minimal synthetic example.

Only the current public release receives fixes. Review [the safety guide](docs/BUILD.md)
for storage, backup exclusions, unknown command outcomes, and background limits.
