The integration fixture uses synthetic SSH authentication in front of the
installed Windows bridge and a real disposable Herdr session. It does not
certify real Windows SSH service/account authentication, physical phones,
background notification delivery, Play Store distribution, or recovery during
actual OS process death. The AGP tested-SDK warning is documented in the build
guide. Multiple same-host/account named sessions cannot attach concurrently.

The release includes the signed APK, corresponding source archive, notices,
build information, and SHA-256 checksums. GitHub's `v0.1.1` tag identifies the
source used for the APK; `BUILDINFO.txt` records its commit. Screenshots are
documentation fixtures and are not runtime evidence of connected private hosts.
