The trust manager checks certificate validity and an exact full SHA-256
certificate pin obtained through the PC's physical QR/address. A wrong pin was
rejected before an application pairing request reached the server. It does not
accept arbitrary certificates or fall back to unencrypted connections.

The two real Herdr integration fixtures used disposable sessions and synthetic
device credentials on a fresh API 36 emulator. No physical phone or existing
app data was modified. The Windows installer's syntax and private ACL helper
were checked; its private dependency runtime and launcher were exercised by the
disposable console fixture. The full installer was not deployed to the work PC.
Physical camera scanning, work-PC inbound firewall access, and logon startup on
that PC remain unverified. The published GitHub release remains 0.1.1.
