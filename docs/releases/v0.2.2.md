# 0.2.2 phone-width fit lifecycle

Checked 2026-10-14. Version code 11, same application ID as 0.2.1.
Release: [v0.2.2](https://github.com/RazvanManolache/herdr-on-the-go/releases/tag/v0.2.2).

Switching tabs or computers releases the unfocused tab's split before the
new tab narrows, so a lingering panel is a one-generation event at most.
Fit traffic runs on a dedicated lane the 2-second status polls cannot
starve, and every transition carries a generation so a stale callback
aborts instead of closing the new split. The viewed tab sends a
`pane.fitTouch` heartbeat every minute; the Windows bridge (0.3.2) reaps
fits unheard from for five minutes and resolves tabs from the live
layout, and its attach sweep also closes unrecorded notice panels while
keeping one pane per tab.
