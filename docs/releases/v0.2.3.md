# 0.2.3 sidebar, session Cancel, and deeper history

Released 2026-10-15. Version code 14, same application ID and release signing
key as 0.2.2. Saved connections and pairings are retained when upgrading.

- The **☰** chat sidebar lists connected computers and opens **Manage connections**.
  Opening connection management keeps existing attached computers connected.
- **Cancel** in the session picker closes an unattached attempt, returns to saved
  connections, and keeps the saved entry.
- **Load earlier** requests another 1,000 lines per step without the old fixed
  2,000-line ceiling. The per-pane cache retains the latest two million characters.
- Windows bridge **0.3.3** accepts deeper reads and larger replies. CLI output
  remains bounded to 2 MiB per read, paired replies to 16 MiB, and incoming
  requests to 128 KiB. Actual history depends on the PC's available scrollback.

Use the bridge source package in the release to update the PC and reconnect
the app. Installing only the Android APK does not update the PC responder.

Checks for this release:

- 43 Android unit tests passed.
- 88 bridge regressions passed, including two consecutive history replies above
  8 MiB after JSON escaping and unchanged incoming-request limits.
- Eight Android/Windows SSH integration tests passed, including a 5,400-line
  history request, same-key lost-reply recovery, and transport cleanup. The fixture
  runs the current source responder without replacing the user's installation.
- Two session-Cancel/sidebar UI tests and two tab-picker UI tests passed.
- Paired integration passed two tests covering approval, pinning, a 70-second
  idle connection, recovery with the same pane/draft, manual disconnect, and revocation.
- Eleven fictional-data screenshots were refreshed; new navigation views were
  visually checked before publication.
- Debug, test, and signed release builds passed; version/signature verified.
  Lint reports zero errors and four existing pinning/icon-configuration warnings.

Documentation screenshots are production Compose screens using fictional
computers, credentials, pairing codes, and terminal output. No physical phone
or work-PC installation is changed by the release checks.
